## Presentation Design Principles

*GE 4120 Elective Laboratory Project*

✿ ─────────────── ✿

</div>

## 🌷 Activity Description

This activity focused on understanding and applying the basic principles of effective presentation design. It introduced different ways to organize information, arrange slide elements, and use visual materials to create presentations that are clear, engaging, and easy to understand.

## 💗 What Have I Learned?

- I learned that an effective presentation should have a clear structure, readable text, and visuals that support the topic.
- I understood the importance of consistent layouts, proper spacing, and appropriate font sizes to make slides more organized.

- I can apply these principles when preparing nursing case presentations, classroom reports, and health education materials.

## ✨ Personal Reflection

This activity helped me understand that a good presentation is not only about providing information but also about communicating it effectively. I realized that proper design can make a topic easier for the audience to understand.

# 🎀 ACTIVITY 06
## Making a Website

### Rosé Ribbon Boutique

*GE 4120 Elective Laboratory Project*

✿ ─────────────── ✿

</div>

## 🌷 Activity Description

This activity involved creating a website using Replit based on our individual interests and design preferences.

For my project, I developed **Rosé Ribbon Boutique**, an online boutique concept featuring stylish, comfortable, and affordable clothing. The concept focuses on providing fashionable options while also considering mid-size shoppers who may have difficulty finding clothing that matches their preferred style and size.

The website follows a soft pastel aesthetic, using baby pink, lavender, butter yellow, and mint as its main colors.

## 💗 What Have I Learned?

- I learned the basic process of creating a website and how HTML, CSS, and JavaScript work together.
- I explored how layout, colors, typography, and content contribute to a website's appearance and usability.
- One challenge was balancing a cute visual style with an organized and easy-to-navigate layout. I addressed this by arranging the content into clear sections and reviewing the design.
- I can improve this project by learning more about responsive design, accessibility, and interactive website features.

**Development Platform:** Replit

## ✨ Personal Reflection

This activity allowed me to explore website creation and express my creativity through digital design. Although my main academic background is nursing, I realized that learning basic website development can also help me develop problem-solving skills and become more familiar with technology.

# 🎀 ACTIVITY 07
## Resume Generating

*Comparative Resume Generation Using Two LLMs*

✿ ─────────────── ✿

</div>

## 🌷 Activity Description

This activity focused on comparative resume generation using two Large Language Models (LLMs). We explored how different AI tools generate professional resumes and compared their outputs based on content, organization, formatting, design, and overall effectiveness.

## 💗 What Have I Learned?

- I learned that different AI tools can produce different resume formats and suggestions even when given similar instructions.
- I understood the importance of organizing personal information, educational backgrounds, skills, and qualifications in a professional and readable format.
- One challenge was determining which generated resume communicated the information more effectively. I addressed this by comparing the outputs based on readability, organization, design, and relevance.
- I can apply this knowledge when preparing professional documents for future opportunities, while ensuring that all personal information and qualifications are accurate.

## ✨ Personal Reflection

This activity helped me understand how AI tools can assist in preparing professional documents. I also realized that human review remains important because generated information must be accurate, appropriate, and relevant to the person's actual qualifications.

As a nursing student preparing for my future profession, I can use this knowledge when developing my own professional resume.
